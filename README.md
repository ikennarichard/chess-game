## ⚙️ Setup & Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/ikennarichard/chess-game.git
   cd chess-game
   ```

2. **Install dependencies**

   ```bash
    npm install
   ```

3. **Run dev server**

   ```bash
   npm run dev
   ```

4. **Run dev server**

   ```bash
   Go to http://localhost:5173
   ```
